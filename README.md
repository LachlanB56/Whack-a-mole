# Whack-a-mole
Whack a mole game coded in C++ on Arduino UNO

Link to the project
https://www.tinkercad.com/things/hKSoX4XShjP-lachlans-whack-a-mole-project/editel?returnTo=https%3A%2F%2Fwww.tinkercad.com%2Fdashboard%2Fdesigns%2Fcircuits

Description: 
Arduino UNO coded in C++ to create the Whack a mole reaction time game, external pull up resistors are used to connect pushbuttons to the Arduino.
